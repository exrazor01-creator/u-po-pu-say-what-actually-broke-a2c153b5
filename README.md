A single line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong: the login expired because the server has the memory of a goldfish. It names the real failure, says what to do next (sign in again), and lands the joke in the last sentence — signing in again will not fix the forgetting.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
